# 入群欢迎 Web 管理面板实施计划

## 可行性结论（已验证）
现有插件已有每群 `{text, image}` 配置、图片落盘与热更新机制，缺的 4 项（默认欢迎词、冷却时间、按钮、群开关）全部可在现有结构上增量实现。面板按**双通道**挂载：只写一份 `webadapter/` 代码，QQBot-Web-Adapter 控制台保底必挂，锅巴启动扫描到 `webadapter/` 目录会自动再挂一份（防御式 init 保证锅巴侧异常不影响 QWA）。

## 配置结构（零迁移）
`data/crystelf/newcomer.json` 保持"群号→配置"扁平结构，只新增保留键（群号不可能以 `_` 开头，无冲突）：

```json
{
  "_default":  { "text": " 欢迎新人~" },
  "_cooldown": 30,
  "481221622": { "enable": true, "text": "...", "image": "/abs/1.jpg",
                 "buttons": [[{"text":"群菜单","callback":"#菜单"}]] }
}
```
- `_default` 默认欢迎词、`_cooldown` 冷却秒数（全局）；每群 `enable` 缺省视为开启（老配置兼容）、`buttons` 为二维数组（一行一个 `segment.button`）
- 模板 `plugins/crystelf-plugin/config/newcomer.json` 同步加保留键，`configControl.init()` 深合并会自动补进 data 侧
- `configControl` 有 fs.watch 热更新 → 面板保存即时生效，无需重启

## 文件改动

**1. `apps/welcome.js`（改）**
- `enable === false` → 直接跳过（不欢迎、不进冷却）
- 冷却改用 `_cooldown || 30` 秒；冷却期内回复 `_default.text`（现在硬编码"欢迎新人~"）
- msgList 末尾按行追加 `segment.button(...row)`（已确认 `segment.button` 存在于 Miao-Yunzai oicq shim，适配器 `makeRawMarkdownMsg` 会组装成官方键盘）
- 无群配置时兜底文案用 `_default.text`

**2. `webadapter/index.js`（新）**
防御式 `init(ctx)`：ctx 缺 `registerPage`/`registerApi` 直接 return（兼容 QWA 与锅巴两种扫描器）。
- `registerPage({id:'crystelf-welcome', title:'入群欢迎管理', icon:'👋', src:'welcome.html'})`
- API 路由（核心逻辑放 `lib/welcome-admin.js` 共用）：`GET /welcome/config`（全局+全部群配置+群列表）、`PUT /welcome/global`、`PUT /welcome/group`（gid 走 body，避开路径参数冒号坑）、`POST /welcome/image`（dataUrl 解码或 URL 服务端下载 → 写 `data/crystelf/newcomer/<gid>/1.jpg|gif|png`）、`DELETE /welcome/image`、`DELETE /welcome/group`、`POST /welcome/test`（向指定群真发一条测试欢迎）
- gid 校验 `/^[\w:-]+$/` 防目录穿越；Bot.express 未就绪时按 QQBot-Plugin/webadapter 范例用 `Bot.on('plugins/loaded')` 延迟注册

**3. `webadapter/welcome.html`（新，自包含单文件，内联 CSS/JS 零外部资源）**
- 顶部全局设置卡（默认欢迎词、冷却秒数）
- 群列表（`Bot[id].gl` ∪ 已配置群号，可搜索）+ 手动输入群号添加
- 群编辑器：启用开关、文本、图片（预览 / 本地上传（前端 canvas 压尺寸后转 dataURL，QWA 已把全局 json limit 提到 200mb）/ 粘贴 URL 服务端下载 / 清除）、按钮编辑器（行管理，每按钮：文案、动作类型 跳链接/回调/发送指令、内容、点击后文案、权限 全员/管理员、可选确认弹窗）
- "测试发送"按钮
- 宿主自适应：`apiBase = query.__apiBase || (query.__webBase || '') + '/api'`，兼容 QWA（`__webBase`+cookie 鉴权）与锅巴（`__apiBase`+token）

**4. `apps/welcome-set.js`（不动）**
聊天命令读写同一配置，自动同步。可选顺手修复：`#查看欢迎` 目前无权限校验，补上与其它命令一致的 master/owner/admin 校验（行为变更，不同意可去掉）。

## 已知边界
- 按钮仅在 QQ 群链路生效；频道群（`guild:channel` 键）适配器会跳过按钮段，仍发文本+图片
- 回调按钮可用性取决于官方 bot 权限（适配器已内置模板支持），以面板"测试发送"真机验证为准
- 冷却期内仍回复默认欢迎词（保持现有防刷屏设计）

## 实施与验证
1. welcome.js + 模板 → 2. lib/welcome-admin.js + webadapter 两文件 → 3. `pm2 restart yunzai` → 4. 验证：QWA 侧边栏出现页面 → 改配置热生效 → 真机测试发送（文本/图片/按钮/开关/冷却）→ 聊天命令同步性抽查 → 锅巴扩展页面入口确认。
